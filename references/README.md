# Design references

The seven user-supplied images and original Workshop 5.2 use case are preserved here. The source document is reference material; the user's pasted request controls this local implementation, including VS Code/Codex documentation and replacing SQS/Lambda with a local worker.

The references informed category browsing, photo-led garment grids, reviewed tags, outfit collages and mobile bottom navigation. The wardrobe/capsule images also informed a neutral, considered visual direction. Screenshots are not used as an application interface and reference garments are never seeded as a user's possessions. The clothing rail illustration in the account/empty dashboard is original SVG artwork, labelled as an illustration.

`workshop-5.2-original.txt` is an unchanged historical source and may mention earlier development tools. Current project documentation uses VS Code and Codex. Proposed pilot metrics and AWS architecture in that source remain unverified targets, not achieved results.
